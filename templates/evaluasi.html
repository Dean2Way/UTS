Klasifikasi stroke, dibandingkan dengan jurnal Sidiq dkk. (JATI, 2024).

1. Sumber dan karakteristik dataset

Dataset Stroke Prediction Dataset dari Kaggle (healthcare-dataset-stroke-data.csv), dataset yang sama dengan jurnal acuan.

  • Jumlah data: {{ m.n_rows }} baris, {{ m.n_cols }} kolom (target: stroke).
  • Kelas stroke: {{ m.n_stroke }} ({{ '%.1f'|format(m.n_stroke / m.n_rows * 100) }}%), tidak stroke: {{ m.n_nostroke }}. Data sangat tidak seimbang (imbalanced).
  • Missing value: kolom bmi kosong pada {{ m.n_missing_bmi }} data.
  • Fitur: gender, age, hypertension, heart_disease, ever_married, work_type, Residence_type, avg_glucose_level, bmi, smoking_status.

2. Preprocessing dan pembagian data

  • Kolom id dibuang (hanya pengenal). Kolom heart_disease juga dibuang, mengikuti jurnal.
  • bmi yang kosong diisi median.
  • Fitur kategorikal diubah dengan One-Hot Encoding; hypertension diperlakukan sebagai kategori.
  • Pembagian data 80:20 (stratified, random_state=42): training {{ m.n_train }}, testing {{ m.n_test }}.

3. Model

Decision Tree (scikit-learn) dengan criterion="entropy", max_depth=10, min_samples_split=4, min_samples_leaf=2. Kedalaman pohon hasil training {{ m.depth }} dengan {{ m.leaves }} daun.

Interpretasi

Akurasi tinggi menyesatkan karena hanya sekitar {{ '%.1f'|format(m.n_stroke / m.n_rows * 100) }}% data adalah stroke: model yang selalu menebak "tidak stroke" saja sudah akurat ±{{ '%.0f'|format(m.n_nostroke / m.n_rows * 100) }}%. Dari {{ m.tp + m.fn }} pasien stroke di data uji, hanya {{ m.tp }} yang terdeteksi (recall {{ '%.2f'|format(m.recall*100) }}%). Secara medis, FN (stroke tidak terdeteksi) lebih berbahaya daripada FP (salah alarm).

Persamaan

  • Dataset, metode (Decision Tree), dan rasio split sama.
  • Akurasi sama-sama tinggi (±94%), tetapi precision dan recall kelas stroke sama-sama rendah.
  • Penyebab utama kesamaan: data sangat imbalanced dan tidak ada penanganan imbalance, sehingga model condong memprediksi "tidak stroke".

Perbedaan dan kemungkinan penyebab

  • Algoritma: C4.5 memakai gain ratio dan pruning, scikit-learn memakai CART dengan entropy dan pembatasan (max_depth, min_samples). Struktur pohon dan prediksi bisa berbeda.
  • Jumlah data uji: jurnal {{ j.n_test }} data, project ini {{ m.n_test }} data, sehingga angka tidak bisa dibandingkan satu-satu. Dengan kelas stroke yang sangat sedikit, selisih beberapa kasus saja mengubah precision/recall secara besar.
  • Missing value: jurnal tidak menjelaskan cara menangani BMI, project ini memakai median.
  • Encoding dan tooling: jurnal memakai RapidMiner, project ini scikit-learn dengan One-Hot Encoding.
  • Random split: pembagian acak yang berbeda menghasilkan hasil yang berbeda.

Catatan: pada jurnal, rumus precision dan recall di subbab evaluasi tertukar dengan abstraknya. Dari confusion matrix (stroke terprediksi benar 2, salah prediksi stroke 14, stroke terlewat 38), precision = 2/16 = 12,5% dan recall = 2/40 = 5%, sesuai abstrak.

6. Kesimpulan

Decision Tree menghasilkan akurasi tinggi, namun kemampuan mendeteksi stroke masih rendah, sejalan dengan temuan jurnal. Akurasi bukan metrik yang cocok untuk data imbalanced; precision dan recall kelas stroke lebih relevan. Perbaikan yang bisa dilakukan: class_weight, oversampling (SMOTE), memakai kembali fitur heart_disease, serta membandingkan dengan Random Forest atau MLP.
